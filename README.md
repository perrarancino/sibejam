# sibejam

## Редактор карты

Нажмите **1** в игре, чтобы открыть или закрыть редактор. Выберите объект и перетащите его мышью, либо выберите тип слева и нажмите на землю. Выберите траву и зажмите левую кнопку мыши, чтобы рисовать. Удерживайте правую кнопку мыши, чтобы стирать объекты выбранного типа. Для забора нажмите один раз или протяните линию из нескольких секций; Начните следующую линию возле крайнего столбика, чтобы соединить её с предыдущей и сделать поворот; R меняет направление одиночной секции. WASD двигает камеру, колёсико приближает, Delete удаляет объект.

Кнопка «Сохранить черновик» сохраняет карту в текущем браузере. Кнопка «Опубликовать: скачать JSON» выдаёт файл готовой карты. Замените им `assets/map.json`, затем закоммитьте и отправьте изменения в репозиторий: после обновления GitHub Pages игра загрузит новую карту. Кнопка «Загрузить JSON» позволяет продолжить редактировать сохранённую карту.
