# sibejam

## Начало истории

В подготовке встаньте в жёлтый круг перед храмом и прочитайте письмо. Выйдите из круга и вернитесь в него, чтобы подтвердить начало обороны. В боевой стадии камеры переключаются цифрами или стрелками, выбранная камера плавно наводится на курсор. Escape открывает паузу с настройками графики и громкости. Волны и бой с Джеком пока не реализованы.

Во время подготовки наведите прицел на свободное место рядом с Агатой и нажмите левую кнопку мыши. Выберите ловушку в круговом меню: её стоимость вычитается из стартовых 100 монет. В первую ночь доступны шипы и мина; остальные ловушки пока закрыты. Наведите курсор на установленную ловушку и нажмите ЛКМ, чтобы убрать её и вернуть монеты. Наведите курсор на установленную ловушку и вращайте колёсико для плавного поворота без изменения зума. R поворачивает выбранную ловушку или направление следующей постройки. Escape, ПКМ или нажатие в центр закрывает меню. Расставленные модели сохраняются на время текущей игры; боевое действие ловушек появится вместе с врагами.

При первом запуске выберите качество графики. Его можно изменить позже через меню «Графика» в правом нижнем углу. Профиль «Картошка» отключает траву и тени, «Нормальный» использует масштаб 75%, «Хороший» — 100%.

## Редактор карты

Нажмите **Tab** в игре, чтобы открыть или закрыть редактор. Выберите объект и перетащите его мышью, либо выберите тип слева и нажмите на землю. Выберите траву и зажмите левую кнопку мыши, чтобы рисовать. Удерживайте правую кнопку мыши, чтобы стирать объекты выбранного типа. Для забора нажмите один раз или протяните линию из нескольких секций; Начните следующую линию возле крайнего столбика, чтобы соединить её с предыдущей и сделать поворот; R меняет направление одиночной секции. WASD двигает камеру, колёсико приближает, Delete удаляет объект.

В разделе «Размер карты и освещение» можно менять размер территории и яркость света; эти параметры сохраняются в JSON вместе с объектами.

Кнопка «Сохранить черновик» сохраняет карту в текущем браузере. Кнопка «Опубликовать: скачать JSON» выдаёт файл готовой карты. Замените им `assets/map.json`, затем закоммитьте и отправьте изменения в репозиторий: после обновления GitHub Pages игра загрузит новую карту. Кнопка «Загрузить JSON» позволяет продолжить редактировать сохранённую карту.

Для проверки визуальных эффектов всех ловушек откройте `/scripts/trap-effects-preview.html` на локальном сервере. Кнопка Activate manual traps запускает ручные ловушки на тестовой площадке.

Шипы автоматически срабатывают раз в секунду при контакте врага с платформой. Катящееся бревно проверяет всю ширину прохода и останавливается у стен. Огонь, жидкость и кровь используют общие материалы и ограниченные наборы частиц; кровь оставляет до 48 постепенно исчезающих пятен.

В боевой стадии ЛКМ по мине подрывает её вручную; при наступании врага мина срабатывает автоматически. На миникарте враги обозначены красными точками, обращённые союзники — зелёными. Текстуры крови взяты с OpenGameArt по CC0; источники указаны в assets/effects/ATTRIBUTION.txt.
